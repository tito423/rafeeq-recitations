# rafeeq-recitations

The [Rafeeq Al-Darb](https://github.com/tito423/Rafeeq-Al-Darb) app's own copy of
the Qur'an recitations it plays, so that playback does not depend on any one
outside server. Nothing here is edited: every file is the original recording,
byte for byte, as published by its source.

- **Ayah by ayah** (`ayah-<folder>-p<N>` releases): from [everyayah.com](https://everyayah.com),
  one file per ayah, named `SSSAAA.mp3`.
- **Whole surahs** (`surah-<moshaf id>` releases): from [mp3quran.net](https://mp3quran.net),
  one file per surah, named `SSS.mp3`.

The sources stay credited in the app's Sources screen and remain its last fallback.
